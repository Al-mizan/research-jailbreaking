# 6. Web-Agent Security

I recently studied the paper:

## WASP: Benchmarking Web Agent Security Against Prompt Injection Attacks

Paper:
https://arxiv.org/pdf/2504.18575

Important concept from WASP:

> **Intermediate attack success ≠ end-to-end attack success.**

An agent may be successfully hijacked but fail to complete the attacker's final objective because the agent is still poor at complex execution.

This led to the interesting concept:

> **Security by incompetence**

Meaning an agent may appear secure because it cannot successfully execute the full malicious workflow, rather than because it correctly detects and rejects the malicious instruction.

This distinction is important for my future benchmark/evaluation work.

# 21. Important Conceptual Distinction for Future Discussions

When discussing this research, distinguish:

### Jailbreak

Model is induced to violate its safety constraints.

### Prompt injection

Attacker-controlled instructions manipulate the model's behavior.

### Indirect prompt injection

The malicious instruction comes from external/contextual content rather than directly from the user.

### Agent hijacking

The agent's intended task/behavior is redirected.

### Tool poisoning

Malicious tool descriptions/metadata influence the agent.

### Skill poisoning

Malicious agent skill files or skill metadata manipulate the agent.

### Supply-chain attack

The malicious component enters through a trusted ecosystem/distribution mechanism.

### End-to-end attack

The attacker actually achieves the malicious objective.

These terms should NOT be treated as interchangeable.
